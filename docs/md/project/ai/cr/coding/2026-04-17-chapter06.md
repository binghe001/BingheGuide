### 2.2 Gitea代码审查流程

```mermaid
sequenceDiagram
    participant Webhook as Gitea Webhook
    participant Handler as GiteaWebhookHandler
    participant CodeReview as CodeReviewService
    participant LLM as LLM Client
    participant DB as Repository
    participant Notifier as NotificationService
    participant Gitea as Gitea API

    Webhook->>Handler: 发送Pull Request事件
    Handler->>Handler: 解析payload（action, pr信息）
    Handler->>Handler: 过滤分支和受保护分支
    Handler->>Handler: fetchPrFiles获取代码变更
    Handler->>Handler: fetchPrCommits获取提交信息

    Handler->>CodeReview: reviewAndStripCode(changesText, commitsText)
    CodeReview->>LLM: 调用LLM API进行审查
    LLM-->>CodeReview: 返回审查结果
    CodeReview-->>Handler: 审查结果和评分

    Handler->>Gitea: postPrComment发布评论
    Gitea-->>Handler: 发布成功

    Handler->>DB: 保存MrReviewLog
    DB-->>Handler: 保存成功

    Handler->>Notifier: sendReviewNotification
    Notifier->>Notifier: 构建通知消息
    Notifier->>Notifier: 多渠道发送通知
```
