### 1.2 实现详情

#### 1.2.1 实现内容

本阶段实现Review和Report服务的核心功能：

**新增文件**:

- `io.binghe.ai.review.service.ReviewService` - 审查记录服务接口
- `io.binghe.ai.review.service.impl.ReviewServiceImpl` - 审查记录服务实现
- `io.binghe.ai.review.service.ReportService` - 日报服务接口
- `io.binghe.ai.review.service.impl.ReportServiceImpl` - 日报服务实现

**核心功能**:

1. 审查记录的增删改查（ReviewService）
2. 日报的定时生成与LLM生成
3. 数据去重与统计分析
4. 降级处理策略

#### 1.2.2 关键技术点

- **定时任务**: @Scheduled注解配置日报生成时间
- **LLM生成日报**: 使用LLMClient调用AI生成结构化日报
- **数据去重**: 基于author和commit_messages组合去重
- **降级策略**: LLM失败时使用简单格式生成日报
- **时间范围查询**: 今日时间范围自动计算
- **多审查类型支持**: MR和Push两种审查类型

## 三、执行流程

### 3.1 审查记录CRUD流程

```mermaid
sequenceDiagram
    participant Webhook as Webhook处理器
    participant Service as ReviewService
    participant MrRepo as MrReviewLogRepository
    participant PushRepo as PushReviewLogRepository
    participant CodeRev as CodeReviewService
    participant LLM as LLMClient
    participant Log as 日志记录

    Note over Webhook,Log: 步骤1: 接收审查请求
    Webhook->>Service: insertMrReviewLog(entity) 或 insertPushReviewLog(entity)

    Note over Service: 步骤2: 保存审查日志
    alt 插入MR日志
        Service->>MrRepo: save(entity)
        MrRepo-->>Service: 保存成功
        Service->>Log: log.info("MR review log saved: {} by {}", projectName, author)
    else 插入Push日志
        Service->>PushRepo: save(entity)
        PushRepo-->>Service: 保存成功
        Service->>Log: log.info("Push review log saved: {} by {}", projectName, author)
    end

    Service-->>Webhook: 保存完成

    Note over Webhook,Log: 步骤3: 查询审查记录
    Webhook->>Service: getMrReviewLogs(authors, projectNames, gte, lte)
    Service->>MrRepo: findByFilters(authors, projectNames, gte, lte)
    MrRepo-->>Service: 返回审查日志列表
    Service-->>Webhook: 返回查询结果

    Note over Webhook,Log: 步骤4: 获取不重复数据
    Webhook->>Service: getMrDistinctAuthors() / getMrDistinctProjectNames()
    Service->>MrRepo: findDistinctAuthors() / findDistinctProjectNames()
    MrRepo-->>Service: 返回不重复数据
    Service-->>Webhook: 返回不重复列表
```

### 3.2 日报生成流程

```mermaid
sequenceDiagram
    participant Scheduler as @Scheduled定时任务
    participant ReportService as ReportService
    participant ReviewService as ReviewService
    participant LLMFactory as LLMFactory
    participant LLMClient as LLMClient
    participant LLM as LLM模型
    participant Log as 日志记录

    Note over Scheduler,LLM: 步骤1: 定时触发
    Scheduler->>ReportService: scheduledDailyReport() (每天18:00)
    ReportService->>Log: log.info("Starting scheduled daily report")

    Note over ReportService: 步骤2: 获取今日时间范围
    ReportService->>ReportService: LocalDateTime.now().atStartOfDay()
    ReportService->>ReportService: LocalDateTime.now().atTime(23, 59, 59)
    ReportService->>ReportService: 转换为时间戳

    Note over ReportService: 步骤3: 查询今日记录
    alt pushReviewEnabled = true
        ReportService->>ReviewService: getPushReviewLogs(null, null, startTs, endTs)
        ReviewService->>PushRepo: findByFilters(null, null, startTs, endTs)
        PushRepo-->>ReviewService: 返回今日Push日志
        ReviewService-->>ReportService: 返回日志列表
    else pushReviewEnabled = false
        ReportService->>ReviewService: getMrReviewLogs(null, null, startTs, endTs)
        ReviewService->>MrRepo: findByFilters(null, null, startTs, endTs)
        MrRepo-->>ReviewService: 返回今日MR日志
        ReviewService-->>ReportService: 返回日志列表
    end

    Note over ReportService: 步骤4: 数据去重
    ReportService->>ReportService: 基于author + commit_messages去重
    ReportService->>ReportService: 按author排序

    alt 记录为空
        ReportService->>Log: log.info("No records for daily report")
        ReportService-->>Scheduler: 返回"今日暂无代码审查记录"
    else 记录不为空
        Note over ReportService: 步骤5: 生成日报
        ReportService->>ReportService: generateReport(dedupedRecords)

        alt LLM生成成功
            ReportService->>LLMFactory: getClient()
            LLMFactory-->>ReportService: LLMClient实例
            ReportService->>LLMClient: completions(messages)
            LLMClient->>LLM: 调用AI模型
            LLM-->>LLMClient: 返回日报内容
            LLMClient-->>ReportService: 返回日报内容
            ReportService->>Log: log.info("Daily report generated")
            ReportService-->>Scheduler: 返回LLM生成的日报
        else LLM生成失败
            ReportService->>Log: log.error("Failed to generate report with LLM")
            ReportService->>ReportService: 生成简单格式日报
            ReportService->>Log: log.info("Generated simple daily report")
            ReportService-->>Scheduler: 返回简单格式日报
        end
    end
```
