AI智能代码审查系统是一个基于Spring Boot的自动化代码审查平台，通过集成大语言模型（LLM）对Git代码变更进行智能审查。内置支持多种AI大模型，例如：deepseek、千问、智谱、openai等等，也可以快速扩展定义其他AI大模型。

内置多种不同语言的优秀提示词，可支持对Java、Python、PHP、Yaml、Vue、Go、C、C++、JS、CSS、MD、SQL、TS、TSX、JSX等不同类型的语言和文件进行Review，对Review结果进行评分，深度剖析存在的问题和修复方案，并对整体代码优化给出建设性建议，并对整体结果进行持久化存储，可供长期分析代码质量。

代码仓库支持GitHub、Gitee和GitLab等，可直接对接钉钉、微信、飞书等推送消息，也可快速扩展自定义对接其他平台，整体项目可直接应用于实际CR场景中。

### 1.2 第三步实现详情

#### 1.2.1 实现内容

本阶段实现了CodeReview服务的核心功能：

**新增文件**:

- `io.binghe.ai.review.service.CodeReviewService` - 代码审查服务接口
- `io.binghe.ai.review.service.impl.CodeReviewServiceImpl` - 代码审查服务实现

**核心功能**:

1. 代码审查主流程
2. 编程语言自动检测
3. 提示词模板加载与处理
4. AI返回结果解析与清理

#### 1.2.2 关键技术点

- **语言检测**: 通过文件扩展名 + 代码特征双维度检测
- **Token管理**: 简单估算（1 token ≈ 4 characters）
- **提示词模板**: YAML + Jinja2语法支持
- **多风格支持**: 专业、讽刺、温和、幽默
- **错误处理**: 多层异常捕获与降级策略

## 三、执行流程

### 3.1 代码审查主流程

```mermaid
sequenceDiagram
    participant Client as 调用方
    participant Service as CodeReviewService
    participant LLMFactory as LLMFactory
    participant LLM as LLMClient
    participant Constants as AiReviewConstants

    Note over Client,Constants: 步骤1: 预处理
    Client->>Service: reviewAndStripCode(changesText, commitsText)

    alt 代码为空
        Service->>Service: log.info("代码为空")
        Service-->>Client: 返回 "代码为空"
    else 代码不为空
        Note over Service: 步骤2: 语言检测
        Service->>Service: detectLanguageFromDiff(changesText)
        Service->>Service: 记录检测到的语言

        Note over Service: 步骤3: Token限制检查
        alt 代码过长
            Service->>Service: 截断代码到maxTokens
            Service->>Service: 重新检测语言
            Service->>Service: 使用截断后的语言
        end

        Note over Service: 步骤4: 调用LLM审查
        Service->>Service: loadPrompts(language, reviewStyle)
        Service->>Service: processTemplate() 处理Jinja2模板

        Service->>LLMFactory: getClient()
        LLMFactory-->>Service: LLMClient实例

        Service->>LLM: completions(messages)
        LLM-->>Service: 审查结果

        Note over Service: 步骤5: 结果清理
        Service->>Service: strip()
        alt 结果包含markdown格式
            Service->>Service: 去除markdown标记
        end

        Service-->>Client: 返回清理后的结果
    end
```

### 3.2 语言检测流程

```mermaid
flowchart TD
    A["开始语言检测"] --> B["输入: diff文本"]
    B --> C["初始化语言计数器和Vue3指标"]
    C --> D["遍历每一行"]

    D --> E{匹配文件路径模式?}
    E -- 是 --> F["提取文件扩展名"]
    F --> G["映射到编程语言"]
    G --> H["增加语言计数"]
    H --> D

    E -- 否 --> I{匹配diff--git格式?}
    I -- 是 --> J["提取文件扩展名"]
    J --> G
    G --> D

    I -- 否 --> K{包含Vue3特征?}
    K -- 是 --> L["增加Vue3指标"]
    L --> D
    K -- 否 --> D

    D --> M{是否检测到语言?}
    M -- 是 --> N["统计各语言出现次数"]
    N --> O["选择出现次数最多的语言"]
    O --> P["返回主要编程语言"]

    M -- 否 --> Q["从内容中检测"]
    Q --> R{包含Vue特征?}
    R -- 是 --> S["标记为Vue"]
    S --> P

    R -- 否 --> T{包含JS特征?}
    T -- 是 --> U["标记为JavaScript"]
    U --> P

    T -- 否 --> V{包含Python特征?}
    V -- 是 --> W["标记为Python"]
    W --> P

    V -- 否 --> X["返回默认语言"]
    X --> P

    P --> Y["记录日志: 检测到的语言, Vue3指标"]
    Y --> Z["结束"]
```

### 3.3 提示词模板加载流程

```mermaid
flowchart TD

    O --> P["返回system_prompt和user_prompt"]

    E --> Q["结束: 抛出异常"]
    I --> Q

```
