## 四、技术选型

对于多轮AI智能对话系统总体技术选型如下：

**（1）后端框架与核心语言**

* 项目基于 Spring Boot 3.2.0 构建，充分利用其开箱即用、快速集成的特性来搭建服务端框架。

* 使用 Java 17 作为核心开发语言，确保应用具备良好的性能与现代语言特性支持。

**（2）AI能力集成**

* 通过 Spring AI 1.0.0-M5 这一里程碑版本集成AI能力框架，它作为抽象层，简化了与大模型的交互。

* AI对话服务由 DeepSeek API 具体提供，负责处理核心的智能对话与内容生成。

**（3）数据管理与缓存**

* 引入 Redis 作为数据存储与缓存层，核心用途是实现对话上下文的记忆与缓存，保障多轮会话的连贯性。

**（4）开发效率与数据交换**

* 使用 Maven 管理项目依赖与构建生命周期。

* 集成 Lombok 库，通过在编译时自动生成代码（如Getter/Setter），极大简化了Java实体类的开发。

* 使用 Jackson 库处理系统中所有JSON数据的序列化与反序列化，确保数据交换的高效与可靠。

**（5）前端交互**

* 前端界面直接由 HTML、CSS 和 JavaScript 构建，专注于实现轻量、响应式的用户交互体验。
